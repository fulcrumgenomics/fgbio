Assembly Report to Sequence Dictionary

fgbio GitHub

Build a SAM sequence dictionary (@HD/@SQ lines) with alternate contig names (AN) from an NCBI assembly report, similar to fgbio's CollectAlternateContigNames. The dictionary can be used with tools such as UpdateContigNames, UpdateVcfContigNames, and UpdateFastaContigNames. See the fgbio wiki for more details. Everything runs in your browser; uploaded or pasted reports never leave your computer.

How this page differs from CollectAlternateContigNames
  • The default primary name is the first of UCSC-style-name, RefSeq-Accn, GenBank-Accn, Sequence-Name and Assigned-Molecule that names every sequence in the default roles, or, if none does, the one that names the most (the CLI defaults to RefSeq-Accn). Alternates default to the other accession, UCSC and Assigned-Molecule columns.
  • By default only assembled-molecule, unlocalized-scaffold, unplaced-scaffold and alt-scaffold sequences are included, sorted in that order (the CLI includes every role in report order). Sequences without alternate names are kept (the CLI skips them).
  • Assigned-Molecule is used only for assembled-molecule sequences, as the primary name as well as an alternate.
  • Names are checked against the SAM specification and must be unique across all SN and AN values: an alternate name that is another sequence's primary name, or is shared by several sequences, is dropped with a warning.
  • AN lists alternates in a fixed column order, an AS tag can be added, and the lowercase report tags are optional.

1Load an assembly report

Reports are downloaded directly from the NCBI FTP site (ftp.ncbi.nlm.nih.gov).

Enter a GenBank (GCA_) or RefSeq (GCF_) assembly accession. Omit the version (e.g. GCF_000001635) to use the latest version. A direct https:// link to an *_assembly_report.txt file also works if the server allows cross-origin requests (NCBI does).
